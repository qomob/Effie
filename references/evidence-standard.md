# 证据标准：什么算"有证据"

> 核心区分：**登记 ≠ 验证；哈希一致 ≠ 内容真实；企业自报 ≠ 独立审计。**

## 1. 证据状态六分级

| 状态 | 定义 | 能否支撑正式主张 |
|---|---|---|
| `VERIFIED` | 原件存在、哈希匹配、位置可定位、原文确实支持该主张、数值/单位/口径/对象一致 | 可以 |
| `PARTIALLY_SUPPORTED` | 原文存在但只支持主张的一部分（如只支持方向不支持量级） | 需降级表述 |
| `USER_ASSERTED` | 仅用户口头/文档声明，无原始数据 | 只可标"（待证）" |
| `UNVERIFIED` | 有材料但未核对 | 不可作为通过依据 |
| `CONTRADICTED` | 存在反证（如两份材料数值冲突） | 必须披露冲突 |
| `MISSING` | 无任何证据 | 必须列入缺口 |

## 2. 一条完整证据记录的必备字段

```
evidence_id            唯一 ID
file                   原始文件名
sha256                 文件哈希
locator                页码 / 工作表 / 单元格 / 时间码
quote                  原文片段或数据锚点
provider               数据提供方
metric                 指标名称
value / unit           数值与单位
scope                  统计对象范围（品牌/品类/地区/渠道）
period                 统计周期（起止日期）
baseline               比较基准
formula                计算公式（若是派生指标）
status                 上述六态之一
confidentiality        保密等级
publication_cleared    是否可公开
```

**缺任一关键字段 → 不得标 VERIFIED。**

## 3. 主张（Claim）与证据（Evidence）的绑定

每个关键主张（尤其是数字主张）必须有唯一 `claim_id`，并显式绑定 ≥1 个 `evidence_id`。

```
claim_id: C-012
text: "活动期间新客占比从 34% 提升至 51%"
type: CALC
evidence: [E-004, E-007]
formula: "(新客数_活动期 / 总客数_活动期) - (新客数_基期 / 总客数_基期)"
verify: 需核 E-004 是否含活动期分母
```

**绑定检查要回答**：
1. 引用的文件是否真实存在、哈希是否一致？
2. 引用的位置是否真有这段内容？
3. 原文是否**真的支持**这个主张（不是"相关"而是"支持"）？
4. 数值、单位、周期、对象是否完全一致？
5. 是否断章取义（原文有限定语被删掉）？
6. 同一个 evidence_id 是否被拿来充当多个独立来源？
7. 不同证据之间是否互相矛盾？

## 4. 高频证据缺陷（必须主动扫）

| 缺陷 | 表现 | 处理 |
|---|---|---|
| 来源虚构 | 引用"XX 研究"但无该研究 | `MISSING` + P0 |
| 页码虚构 | 引用位置无对应内容 | `UNVERIFIED` + P0 |
| 张冠李戴 | 真实文件支持的是另一件事 | `CONTRADICTED` |
| 数值不一致 | 正文写 51%，附件写 41% | `CONTRADICTED` |
| 周期不一致 | 主张"活动期"但数据含活动前 | `PARTIALLY_SUPPORTED` |
| 一证多源 | 同一份数据被写成"三个来源印证" | `MISSING`（独立来源不足） |
| 口径漂移 | 分子分母来自不同人群 | 要求重算 |
| 平台指标冒充生意指标 | 用曝光/互动代替销售 | 降级为战役层证据 |

## 5. 证据强度阶梯（用于判断"够不够"）

```
1 级（最弱）  企业内部口头/PPT 结论
2 级          企业系统后台原始导出（未审计）
3 级          第三方平台数据（电商/媒体后台）
4 级          第三方调研机构报告（可追溯方法）
5 级          独立审计 / 实验设计 / 计量模型结论
```

**艾菲要求**：数据须"具体、可验证的来源"。2 级可接受但需说明来源与口径；
涉及核心因果主张时，仅 1–2 级证据不足以支撑"营销导致"的表述，应改为"与…同期发生"。

## 6. 保密与公开的分离

必须区分两套材料：

| 材料 | 是否含机密 | 处理 |
|---|---|---|
| 书面参赛表（四支柱） | 可含机密 | 可选择"按提交版本发布"或"按编辑版本发布" |
| 创意视频 / 创意平面 / 案例概述 / 实效性声明 | **不可含机密** | 入围即公开发布 |

**敏感数据保护做法**：用百分比或指数表达替代绝对值，并说明指数含义与算法。
这不是隐瞒，是官方推荐做法（手册明示）。

## 8. 判定口诀

- **有文件**不等于**有证据**
- **有证据**不等于**能证明这个主张**
- **能证明**不等于**能证明因果**
- 每一步都要单独过关，不允许跳级
