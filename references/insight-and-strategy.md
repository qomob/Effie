# 洞察与策略质量判定

> 对应第二部分（多数奖项 23.3%，GLOBAL/SCENARIO 25%）。这部分是"专业含量"最集中的地方。

## 1. 洞察的三层结构

一个合格的洞察 = **张力 + 机制 + 可行动性**

```
张力：受众想要 A，但现实/自我认知迫使他们做 B
机制：为什么会有这个矛盾（心理/社会/文化/经济动因）
可行动：品牌可以扮演什么角色来化解这个矛盾
```

**反例**（常见伪洞察）：
- "年轻人越来越注重健康" — 无张力、无机制
- "消费者希望物有所值" — 永恒真理，等于没说
- "Z 世代更愿意为情绪价值买单" — 结论先行，无法推出具体策略

**正例结构**（参考某餐饮案例的公开表述逻辑）：
> 表面上他们要的是便宜，实际上周四的折扣是他们一周里唯一被允许"放纵"的时刻。
> 因此品牌不该再比拼折扣力度，而应成为这个"放纵时刻"的仪式载体。

张力（省钱 vs 想放纵）+ 机制（情绪临界点）+ 可行动（从价格战转向仪式化）= 完整洞察。

## 2. 洞察来源的合法性

官方允许洞察来自：调研、数据、分析、灵感。但**表述时必须标明来源类型**：

| 来源 | 写法 | 可信度 |
|---|---|---|
| 定量调研 | "据 N=1,200 的线上调研（2025.03，XX 机构）" | 高 |
| 平台数据 | "据平台搜索词增长数据（2025.01–06）" | 中高 |
| 定性访谈 | "基于 24 场深访（2025.02）" | 中 |
| 社交媒体观察 | "基于 XX 平台 UGC 语义分析" | 中 |
| 团队判断/灵感 | "基于团队对品类的长期观察" | 低，需标为推断 |

**禁止**：把"灵感"包装成"研究"；编造样本量与机构名。

## 3. 策略质量的四问测试

| 测试 | 问题 | 不通过的信号 |
|---|---|---|
| 排他性 | 竞品用同样策略会显得合理吗？ | 会 → 策略不专属 |
| 因果闭合 | 策略动作→受众反应→商业结果的链路每环都有机制？ | 有断环 |
| 资源匹配 | 以该预算能做出来吗？ | 靠"豪掷"成立 |
| 可证伪 | 如果策略错了，会出现什么反证？ | 想不出 → 不可检验 |

## 4. 创意与策略的咬合度

官方第三部分要评"策略和创意实施"，核心是**创意是否解决了策略要解决的问题**。

| 咬合度 | 表现 |
|---|---|
| 强 | 去掉这个创意，策略就无法成立 |
| 中 | 创意能承载策略，但换个创意也行 |
| 弱 | 创意与策略各说各话（常见：策略讲"情感共鸣"，创意是产品功能片） |
| 无 | 创意甚至与策略冲突 |

**检验方法**：用一句话说出"策略要改变什么行为"，再问"这个创意如何促成该行为"。
答不上来 = 咬合弱。

## 5. 受众界定的专业度

官方 2.1 要求：人口统计 + 文化 + 媒体行为；说明是现有/新受众；计划改变哪些观念与行为。

**分层写法**（推荐）：
```
核心层：已有购买者中频次可提升的人群（占比 X%，贡献 Y% 销售额）
扩展层：品类轻度用户/竞品摇摆者（规模 Z）
辐射层：泛人群（声量扩散）
```
比"18–35 岁女性"专业得多，因为它和生意挂钩。

## 6. 第二部分的高频扣分点

1. 洞察 = 现象描述（L0）
2. 受众只有人口统计，没有行为/媒体画像
3. 洞察与策略之间缺"所以"（推导断裂）
4. 策略讲得宏大，但看不出与本次预算/周期匹配
5. 2.3 写成了执行清单（应为策略内核）
6. 洞察没有出处，或出处不可追溯

## 7. 与其它部分的咬合检查

写完后必须自检这条链：

```
1.1 挑战（商业问题）
  → 1.2 目标（可量化）
    → 2.1 受众（谁能解决这个商业问题）
      → 2.2 洞察（他们为什么现在没这么做）
        → 2.3 策略（品牌做什么能改变他们）
          → 3.x 执行（具体怎么做）
            → 4.1 成果（行为变了吗，生意变了吗）
              → 4.2 归因（是不是别的原因）
```

任一环断裂，都要在诊断中指出具体位置（字段号 + 原文引用）。
