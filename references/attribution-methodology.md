# 营销归因审查方法

> 艾菲的第四部分本质是**归因论证**。评委明说："本部分围绕为何是营销导致实现了这些成果，
> 排除其他可能有助于你成功的因素"。所以归因不是可选项。

## 1. 结论五分级（必须用这套措辞）

| 级别 | 表述 | 成立条件 |
|---|---|---|
| **A. 有充分证据支持的因果贡献** | "本活动贡献了 X% 的增量" | 有对照/实验/模型，且方法前提成立 |
| **B. 有一定证据支持的营销贡献** | "多重证据一致指向该活动是主要驱动因素之一" | 多条独立线索收敛，但无严格对照 |
| **C. 仅存在相关性** | "活动期间该指标同步显著提升" | 只有时序或前后对比 |
| **D. 无法确定营销贡献** | "现有数据无法区分营销与其它因素的作用" | 数据不足 |
| **E. 存在相反证据** | "数据显示同期存在更强的替代解释" | 有反证 |

**禁止**把 C 写成 A。**禁止**用"赋能""引爆""带动"等词隐式跨越因果。

## 2. 必须排查的 14 类替代解释

| # | 替代因素 | 排查问题 |
|---|---|---|
| 1 | 季节性 | 去年同期同一时段是否本来就有峰值？ |
| 2 | 行业整体增长 | 品类整体同期涨幅多少？品牌是否跑赢？ |
| 3 | 产品升级/换代 | 同期是否有新品、配方、包装变化？ |
| 4 | 降价与促销 | 是否伴随折扣、满减、赠品？ |
| 5 | 渠道扩张 | 是否新增门店、新平台上架、新分销？ |
| 6 | 铺货率变化 | 可见库存/上架率是否提升？ |
| 7 | 竞品退出/失误 | 竞品是否涨价、断货、翻车？ |
| 8 | 价格变化 | 单价变动对销售额的贡献占比？ |
| 9 | 宏观环境 | 政策、经济、气候、疫情等 |
| 10 | 品牌历史趋势 | 活动前 12 个月的基线斜率如何？ |
| 11 | 自然增长 | 无营销时该指标的常态增速？ |
| 12 | 同期其它营销活动 | 是否有并行的品牌活动、电商大促、代言人事件？ |
| 13 | 统计口径变更 | 是否改了归因窗口、去重规则、渠道口径？ |
| 14 | 数据质量 | 是否有重复计数、机器人流量、退货未扣减？ |

**4.2 字段要求主动陈述这些因素**，且官方列了 6 个勾选项：
商业事件、社会/经济事件、内部公司事件、公共关系、自然事件、同期其它营销活动。

## 3. 可用的归因方法（按数据能力选，不可越级）

| 方法 | 所需数据 | 强度 | 成立前提 |
|---|---|---|---|
| 前后对比 | 活动前后指标 | 弱 | 几乎无前提，但结论只能到 C 级 |
| 同比对照 | 去年同期 | 弱-中 | 季节性稳定 |
| 品类基准对照 | 品类整体数据 | 中 | 能拿到品类口径 |
| 对照组实验 | 未投放组 | 强 | 组间可比、无交叉污染 |
| A/B 测试 | 随机分流 | 强 | 随机化成立、样本足够 |
| 地域实验 | 投放区 vs 对照区 | 强 | 区域独立性、无外溢 |
| 双重差分（DID） | 处理组+对照组×前后 | 强 | 平行趋势成立 |
| 增量测试（holdout） | 有意保留未投放人群 | 最强 | 预算允许、样本足够 |
| 营销组合模型（MMM） | 多期多渠道数据 | 中-强 | 数据长度足够、共线性可控 |

### 3.1 不可越级的硬规则

- 只有前后数据 → **禁止**使用 DID、增量、MMM 的措辞
- 无平行趋势检验 → **禁止**声称 DID 结果
- 样本量不足/无随机化 → **禁止**称"实验证明"
- 数据周期 <2 年 → MMM 结论不可靠，应声明局限

> **禁止为案例虚构实验、研究、调研或归因结果。** 没做就写没做。

## 4. 增量拆解的实操顺序

1. **总变化** = 活动期指标 − 基期指标
2. 减去 **自然增长**（用活动前趋势外推）
3. 减去 **季节性**（用去年同期同比例修正）
4. 减去 **价格/促销** 的量的效应（价格弹性或直接对比同价期）
5. 减去 **铺货/渠道** 扩张带来的可得性提升（按新增覆盖人口折算）
6. 减去 **竞品让出的份额**（如可获取）
7. 余量 → 才可归因于营销传播
8. 给余量一个**区间**，而不是一个精确点值

**若无法完成上述拆解**，结论最多到 C 级，并明确写出"未能排除的因素清单"。

## 5. 常见的伪专业表述（发现即改）

| 伪专业 | 问题 | 改法 |
|---|---|---|
| "ROI 达到 8.5" | 未说明是 ROI 还是 ROAS，分母含什么 | 写清"ROAS = 销售额/媒体费 = 8.5；未计制作与人力" |
| "曝光 11 亿，触达 8 亿人" | 曝光≠去重触达，且 8 亿接近中国网民上限 | 改为"曝光 11 亿次；去重触达 X 亿（平台口径）" |
| "增长 200%" | 基数未给，可能是 1 万→3 万 | 补基数与绝对值 |
| "提升 5 个百分点" 写成 "提升 5%" | 百分点 vs 百分比 | 按实际口径二选一，并前后一致 |
| "全网销量第一" | 无来源、无范围、无时间 | 给出平台、类目、时间窗、数据源 |
| "品效合一" | 无定义 | 拆成品牌指标与效果指标分别给数 |

## 6. 与第四部分字段的对应

| 官方字段 | 归因要求 |
|---|---|
| 4.1 成果概述 | 给区间与对照，不给孤立点值 |
| 4.1 各目标对应成果 | 目标 → KPI → 成果，逐一对应，标注时间窗 |
| 4.1 背景信息 | 解释"这个数字对生意意味着什么"，不是重复数字 |
| 4.2 其它影响因素 | **主动**列出并量化其影响，展示你已排除 |
| 数据来源 | 每个数字都要标注时间框架（官方硬要求） |

> 4.2 写得越诚实，4.1 越可信。回避 4.2 是最常见的扣分点。
