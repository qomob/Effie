## 2. 必须逐奖项核对的五项

### 2.1 评分权重（三套并存）

- 默认（10 个奖项）：挑战 23.3% / 洞察 23.3% / 执行 23.3% / 成果 30%
- `EFFIE_GLOBAL`：**15% / 25% / 30% / 30%**
- `EFFIE_SCENARIO`：**15% / 25% / 30% / 30%**，且**户外媒体营销子类别**为 15/30/30/25

> 用错权重会直接算错加权分，并误导"该往哪补"的判断。
> 取权重必须用 `rule_query.py --award <id> --type scoring_weights`。

### 2.2 地域口径（一条相反）

- 其余 12 个奖项：案例须在**大中华区（中国大陆及港澳台）**投放实施
- `EFFIE_GLOBAL`：案例须在**海外地区**投放实施

> 拿大中华区案例报全球化奖 = 资格 BLOCKED。反向亦然。

### 2.3 材料体系（两套）

| 体系 | 奖项 | 提交物 |
|---|---|---|
| A. 创意视频 + 创意平面 | 其余 10 个 | 1 条视频（≤3min，持续成功类 ≤4min，≤50MB）+ 1–2 张平面 |
| B. 案例阐述 PDF + 投放素材 | GLOBAL / PRA / DIA | 案例阐述（PDF，按官方 PPT 模板）+ 投放素材（图片/视频） |

`EFFIE_SCENARIO` 特殊：视频**可选**，平面 **1–5 张**。

## 3. 通用铁律（13 个奖项一致）

| 项 | 值 |
|---|---|
| 参赛资格窗口 | 2025-01-01 ~ 2026-06-30（须在此窗口内投放实施） |
| 2026-06-30 后才实施 | 不可参赛 |
| 成果数据 | 以窗口内数据为主；窗口外结果须与案例直接相关 |
| 类别上限 | 同一营销活动 ≤4 个类别：1 行业类+3 专项类，或 4 专项类；行业类最多 1 个 |
| 盲评 | 参赛表与全部材料（含文件名）不得出现代理公司名称/LOGO |
| 数据来源 | 每个数据/论断须有可验证来源；无来源即取消资格 |
| 语言 | 参赛表须中文；非中文创意材料须配中文翻译/字幕 |
| 报名费 | 含税 6%；分轮递增；提交成功后不退 |
| 表彰信息修改 | 2500 元/处；2026-10-01 后不接受修改 |

## 4. 常见误用（本 Skill 必须主动拦截）

1. ❌ 拿 `EFFIE_GC_MAIN` 的 23.3% 去算全球化奖的加权分
2. ❌ 把大中华区案例报 `EFFIE_GLOBAL`
3. ❌ 给公关奖客户做"创意视频脚本"（该奖用案例阐述 PDF）
4. ❌ 用主奖项 134 个类别去匹配汽车奖案例
5. ❌ 说"九条取消资格"套到汽车奖
6. ❌ 给场景营销奖交 2 张以上平面却按 1–2 张规范检查
