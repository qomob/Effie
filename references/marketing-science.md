# 营销科学与指标口径

> 用于 M05（实效分析）与 M06（数据审计）。目标：把"看起来专业的数字"变成"经得起追问的数字"。

## 1. 指标族谱（别混）

### 1.1 生意结果层

| 指标 | 定义 | 常见误用 |
|---|---|---|
| 销售额（Revenue） | 实际确认收入（扣退货/折扣） | 用 GMV 冒充 |
| GMV | 成交总额，含未付款/退货 | 当收入用 |
| 销量（Volume） | 件数/吨数/箱数 | 与销售额混用 |
| 毛利 / 毛利率 | 收入−销货成本 | 用销售额增长率替代利润增长 |
| 市场份额 | 品牌销售额 / 品类销售额 | 用"细分市场"自定义分母扩大份额 |
| 渗透率 | 购买过该品牌的家庭/人数 ÷ 目标总体 | 用"触达"冒充 |
| 客单价（AOV） | 销售额 ÷ 订单数 | 与单件价混淆 |
| 复购率 | 二次及以上购买人数 ÷ 首购人数 | 未限定时间窗 |

### 1.2 消费者中间层

| 指标 | 定义 | 常见误用 |
|---|---|---|
| 品牌认知（Awareness） | 提示后/未提示提及率 | 未说明提示与否 |
| 品牌偏好 | 偏好度/首选率 | 与好感度混用 |
| 购买意向 | 未来购买可能性 | 当实际购买 |
| 考量集（Consideration） | 进入候选名单比例 | 与认知混用 |
| NPS | 推荐者% − 贬损者% | 样本与行业基准缺失 |

### 1.3 传播执行层

| 指标 | 定义 | 常见误用 |
|---|---|---|
| 曝光（Impression） | 展示次数（含重复） | 当触达 |
| 触达（Reach） | 去重人数 | 与曝光混用 |
| 频次（Frequency） | 曝光 ÷ 触达 | — |
| 互动率 | 互动数 ÷ 曝光 | 分母用触达 |
| 完播率 | 完整播放 ÷ 播放 | 未说明"完整"定义 |
| CPM / CPC / CPA | 千次曝光/点击/行动成本 | 分母口径不一致 |

### 1.4 效率与回报

| 指标 | 公式 | 关键点 |
|---|---|---|
| ROI | (增量利润 − 投入) ÷ 投入 | 用**利润**，不是销售额 |
| ROAS | 销售额 ÷ 媒体费 | 用**销售额**，不含利润；不含制作人力 |
| CAC | 总获客成本 ÷ 新增客户数 | 是否含人力/技术成本要说明 |
| LTV | 客户生命周期总贡献毛利 | 折扣率与留存假设要披露 |
| LTV/CAC | — | 行业基准差异极大，须给基准来源 |
| 增量收入 | 活动期收入 − 反事实收入 | 反事实怎么估是关键 |

> **ROI ≠ ROAS**。这是中国营销材料里最高频的错误。ROI 用利润，ROAS 用销售额。
> 把 ROAS=8 说成 "ROI 8 倍" 会让评委直接质疑数据严谨性。

## 2. 十二类口径陷阱（审计清单）

| # | 陷阱 | 检查方法 |
|---|---|---|
| 1 | 同比 vs 环比混淆 | 看基期是否去年同期 |
| 2 | 百分比 vs 百分点 | "从 3% 到 5%" 是 +2 个百分点，不是 +2% |
| 3 | GMV vs 收入 | 看是否扣退货与未付款 |
| 4 | ROI vs ROAS | 看分子是利润还是销售额 |
| 5 | 曝光 vs 去重触达 | 看是否说明去重 |
| 6 | 低基数效应 | 看基期绝对值；增长率高可能因基数小 |
| 7 | 统计周期不一致 | 各数字的时间窗是否同一段 |
| 8 | 分母/样本口径不一致 | 分子分母是否同一人群、同一渠道 |
| 9 | 重复累计 | 跨渠道是否去重 |
| 10 | 虚假精确性 | "提升 37.42%" 是否有此精度 |
| 11 | 选择性披露 | 只报好的指标，坏的缺失 |
| 12 | 无基准 | 只有自身数字，无品类/历史对照 |

## 3. 低基数效应速判

```
增长率 = (本期 − 基期) / 基期
```

当基期很小（如 1,000 → 5,000，增长 400%），绝对增量仅 4,000。判断：
- 若绝对增量相对品牌规模可忽略 → 增长率的营销意义有限
- 必须同时给绝对值与占品牌总量的比例

## 4. 增量测算的四种朴素做法（无实验时）

1. **趋势外推**：用活动前 12 个月拟合基线，外推活动期反事实
2. **同群对照**：找可比品牌/可比区域做参照
3. **断点回归**：活动起止作为断点，看斜率是否跳变
4. **份额法**：品牌份额变化 vs 品类份额变化

**都属估算**，结论最多 B 级，须给区间与假设。

## 5. 品牌 vs 效果指标的对应

| 目标类型 | 该看什么 | 不该只看 |
|---|---|---|
| 认知类 | 未提示认知、品牌联想、搜索指数 | 曝光量 |
| 态度类 | 偏好度、情感倾向、NPS | 互动数、点赞 |
| 行为类 | 试用率、首购率、复购频次 | 点击率 |
| 生意类 | 销售额、份额、毛利、新客数 | GMV、曝光 |

**关键原则**：目标在哪个层，成果就必须在哪个层给出。用曝光回答生意目标 = 成果薄弱（官方明示会被判薄弱）。

## 6. 数字表述规范

- 一律给：数值 + 单位 + 周期 + 范围 + 来源
- 增长率同时给绝对值
- 用"个百分点"表述比例变化
- 精度不超过数据本身精度
- 派生指标给公式
- 区间优于点值（尤其归因类）

## 7. 快速核算脚本

```bash
python3 scripts/validate_metrics.py --file metrics.json
```

会检查：单位一致性、周期一致性、ROI/ROAS 混用、百分点误写、分母缺失、
无基准、虚假精度、选择性披露（指标数量与目标数量不匹配）。
