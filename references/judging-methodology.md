# 评审方法：艾菲评委怎么看案例

> 来源依据：2026 各奖项参赛手册"评审"章节。以下为流程事实 + 专业还原。

## 1. 流程事实（官方）

| 项 | 事实 |
|---|---|
| 轮次 | 两轮（初审 → 终审），均为盲评 |
| 打分方式 | 匿名打分 + 匿名评语 |
| 回避原则 | 评委不评审自己服务/来自的品牌及其直接竞品（案例须填竞品，最多 6 个） |
| 评审量 | 每位评委全天审阅 **15–25 件**案例 |
| 四支柱权重 | 按奖项取值（见 `award-index.md`，三套并存） |
| 等级奖 | 金/银/铜/全场大奖；须达对应最低分数线；一个类别可能产生多个等级奖，也可能颗粒无收 |
| 全场大奖 | 得分最高的金奖得主角逐，由资深评审团评选 |
| 评委构成 | 企业营销负责人（总监/VP/CMO+）、10 年以上从业、有大中华区市场经验、近 3 年艾菲经验 |

**由此推出的三条写作约束**：
1. 评委**不认识你的品牌**（回避原则决定了他大概率不在你的品类）→ 必须补足背景，术语要定义。
2. 评委**一天看 20 件**→ 前 100 字抓不住就完了；结构清晰 > 文采。
3. 评委**看不到外部链接**→ 所有引用必须在表内自足。

## 2. 对抗式评审

专业协议的唯一执行入口为 `workflows/jury-simulation.md`，与 `value-discovery.md` 共享目标、证据和决策标准。单模型多角度质疑不是独立评委团。仅在用户需要内部算术诊断时调用已核实权重；不将内部主观分数解释成官方评分、获奖概率或确定的得分变化。官方流程与权重均为继承快照，正式使用前核对原件。
