## 架构减法
八份重点诊断/价值/选案/评审协议及模板（case-diagnosis、portfolio-selection、jury-simulation、value-discovery、judging-methodology、effectiveness-framework、对应两个模板）的 UTF-8 总字节由 26,979 降至 15,028，减少 44.3%。统一专业决策协议，移除固定投报分数、固定类别数量及费用猜测、评委加扣分预测；仍保留可选权重算术诊断及原知识库。不是 Token 实测，不代表专业质量非劣效；逻辑六模块不等同六个独立 Agent。

## 重要限制和自行决定的取舍
- 自动预检严格支持完整源记录、紧凑文本事实及有限跨期计算；非结构化材料、其他计算、比例差值及强因果转人工，可能增加误杀与补证成本。不能用人工转录替代真实原始材料；不认证原始来源的真实性，也不保证全面语义蕴含或组合主张正确。源记录中的基线和分母本身仍待核实。
- 所有正式主张必须 FACT/CALC，未证推断只能留草稿。输入契约有破坏性变更。历史 Schema 未全量迁移/强制执行，实际约束由运行时校验。
- 保持 2026 规则快照及主奖项通用单类别预检范围；专项奖项、持续成功专用表、编辑公开版、多类别一致性、最终真实文件反查及真实签署须人工。未独立复核官方语料或当期报名状态。
- 最高状态 READY_FOR_HUMAN_REVIEW；没有提交授权机制。真实客户、真实宿主、真实模型对照与独立人工盲评均未执行。M6 协议见 `BLIND_EVALUATION_PROTOCOL.md`，不可据此宣称 Token 节省或专家能力提升。
