# M6 真实模型及专业盲评协议（未执行）
A：同等官方资料+普通模型；B：同等资料+精简专业提示词；C：同等资料+V1.1.0；D：同等资料+V1.1.1。所有组同一模型版本、推理预算、原始材料、工具权限和输出结构；记录模型、参数、时间、Token、工具日志和错误。匿名随机排序由独立专业评委评估；评委不知组别，先独立评分再处理分歧。每类用经授权真实案例；另以合成攻击隔离评价安全。不能把工具命中当作专业盲评。

任务：案例价值发现、类别决策、归因与证据审查、低质拒绝、补证计划、完整材料制作。记录准确性、证据覆盖、误杀、人工返工时间、Token 和成功率。建议阈值：重大攻击错误放行0（限预设测试集）；真实重要主张覆盖100%；类别 Top3≥90%；优质误杀≤10%；相对B专业盲评提升≥20%；人工时间节省≥40%；D相较C Token降低≥30%，质量非劣效边界须在实验前注册。样本规模、预算和真实评委需由项目方确认；上述均为待验目标，不是实测。

模块减法实验：保留所有确定性门禁，逐项对照诊断、反方协议、投报组合、可选评分及参考材料的按需加载，禁止以单模型自评替代独立评委。记录差异并回滚导致关键质量下降的减法。未经真实模型/人工对照不得冻结生产架构。
