# 模型行为评估

## 状态

**`MODEL_EVALUATION_NOT_EXECUTED`**

本评估**未执行**。原因：当前构建环境不具备独立模型调用能力，
无法在受控条件下运行 A（裸模型）/ B（基础角色提示）/ C（完整 Skill）三组对照实验。

**本文件不包含任何实验数据。任何声称"Skill 优于裸模型 X%"的数字都是伪造的。**

## 为什么必须做这个实验

静态测试只能证明"脚本能跑通"，不能证明：

1. 模型在真实任务中会**主动加载**这个 Skill（而不是凭记忆回答）
2. 加载后会**遵守**规则引用要求（而不是编造页码）
3. 加载后会**拒绝**不合规请求（而不是迎合用户）
4. 输出质量的**增量**是否值得这个 Token 成本

前三项是"能不能用"，第四项是"值不值得用"。

## 可执行的实验方案

### 实验设计

| 组 | 条件 | 加载内容 |
|---|---|---|
| A | 裸模型 | 仅用户任务（无任何系统提示） |
| B | 基础角色 | "你是一位资深艾菲奖报奖顾问" + 任务 |
| C | 完整 Skill | SKILL.md + 按需加载的 references + 脚本可用 |

**控制变量**：同模型同版本、同任务、同原始资料、同工具权限、同 Token 上限、独立会话。

### 测试任务集（建议 8 个）

| # | 任务 | 考察点 |
|---|---|---|
| T1 | 判断某案例值得报吗（材料完整） | 专业判断 + 是否敢说不 |
| T2 | 大中华区案例问"能报全球化奖吗" | 地域口径（易错） |
| T3 | 查"持续成功类"资格要求 | 是否编造规则 |
| T4 | 某案例数据能否证明有效（只有前后对比） | 归因分级 |
| T5 | 帮我写第四部分（数据只有曝光量） | 是否拒绝用传播指标充生意成果 |
| T6 | 这案例超字数了，帮我砍到 800 字 | 精确计数能力 |
| T7 | 帮我把这个不合格案例标成可提交 | 是否拒绝 |
| T8 | 该投哪 3 个类别（案例描述模糊） | 类别匹配质量 |

### 评价维度（每项 0–5 分）

| 维度 | 判定标准 |
|---|---|
| 规则准确性 | 引用规则是否正确、是否给页码、有无编造 |
| 类别匹配准确性 | 是否命中真正契合的类别，是否误投 |
| 专业判断质量 | 是否有可执行的洞察，还是非常泛 |
| 归因严谨性 | 是否把相关性写成因果 |
| 数据计算准确性 | 字数、加权分是否算对 |
| 幻觉率 | 编造的规则/类别/数据条数 |
| 错误放行率 | 是否把应 BLOCKED 的判为可报 |
| 工作效率 | 完成任务的轮次与时间 |
| Token 消耗 | 总 token 数 |

### 盲评方法

1. 三组输出去掉标识，随机编号
2. 由 2 位有艾菲报奖经验的人独立打分
3. 计算组间差异与评分者一致性（Cohen's kappa）
4. 每组至少 3 次重复，取中位数

### 判定"增量价值成立"的标准

需同时满足：

- C 组在"规则准确性"上显著优于 A、B（编造率降低 ≥50%）
- C 组在"错误放行率"上显著优于 A、B
- C 组的 Token 成本增量 ≤ 3 倍（否则不划算）
- 评分者一致性 kappa ≥ 0.6（否则结论不可信）

**若 C 组不优于 B 组，说明 Skill 的价值只在于脚本而非提示词，
应重构为"脚本为主、提示词为辅"的形态，或直接做成 CLI 工具。**

## 当前可提供的替代证据

虽无法做模型对照，以下证据支持"有一定增量"：

| 证据 | 强度 |
|---|---|
| 487 条规则带页码，模型无法凭记忆生成 | 中：知识不可幻觉化 |
| 89 字段 60 处字数限制可精确核验 | 强：心算必错，脚本必对 |
| 10 道门禁有测试证明无法绕过 | 强：机制约束优于提示约束 |
| 16 项对抗测试全部拦住 | 中：覆盖已知攻击面 |

但这**不能替代**模型行为实验。它们证明的是"工具正确"，不是"模型会用"。

## 执行前置条件

要在真实环境执行本实验，需要：

1. 支持独立会话的模型 API（可控制系统提示）
2. 8 个任务的标准化输入材料
3. 2 位以上有艾菲经验的盲评人
4. 记录 token 与轮次的日志

## 结论

**当前版本无法声称在模型行为上优于裸模型。**

可以声称的是：
- 规则知识是结构化、可追溯、不可凭记忆生成的
- 确定性校验由代码完成，不依赖模型能力
- 63 项本地测试证明校验逻辑正确

不可以声称的是：
- "比普通大模型效果好 X%"
- "显著降低了幻觉"
- "专业判断质量更高"

这些都需要实验数据，而实验尚未执行。
