# 工作流：证据审计（evidence-audit）

**对应模块**：M06　**触发**："帮我检查这些数据来源靠不靠谱"

## 三句话原则

- **登记 ≠ 验证**
- **哈希一致 ≠ 内容真实**
- **企业自报 ≠ 独立审计**

## 步骤

### 1. 建证据登记簿

用 `templates/evidence-register.csv`。每条证据 16 个字段：

```
evidence_id, file, sha256, locator, quote, provider, metric, value, unit,
scope, period, baseline, formula, status, confidentiality, publication_cleared
```

### 2. 建主张登记

每个关键数字/结论一条 claim：

```
claim_id, text, type(FACT/CLAIM/CALC/INFERENCE), evidence_ids, value, unit, period
```

### 3. 跑审计

```bash
python3 scripts/verify_evidence.py --file evidence.json --base-dir ./materials
```

### 4. 九项检查含义

| 检查 | 发现什么 |
|---|---|
| E01 字段完整 | 缺 period/locator 等关键字段 |
| E02 哈希一致 | 文件被改过 / 文件不存在（虚构来源） |
| E03 位置可定位 | 只说"客户提供"无页码 |
| E04 主张绑定 | FACT/CALC 无证据 / 绑定不存在的 ID |
| E05 数值一致 | 主张 51%，证据 41% |
| E06 一证多源 | 同一份文件被当三个独立来源 |
| E07 互相矛盾 | 两条证据冲突 / 存在 CONTRADICTED |
| E08 强度不足 | 称因果但证据仅内部 PPT 级 |
| E09 机密外泄 | 高保密数据进了公开材料 |

### 5. 六态判定

| 状态 | 判定条件 | 可否支撑主张 |
|---|---|---|
| `VERIFIED` | 文件在、哈希对、位置对、原文支持、数值口径一致 | 可以 |
| `PARTIALLY_SUPPORTED` | 只支持方向不支持量级 | 需降级表述 |
| `USER_ASSERTED` | 仅声明 | 标"（待证）" |
| `UNVERIFIED` | 有材料未核对 | 不可 |
| `CONTRADICTED` | 有反证 | 必须披露 |
| `MISSING` | 无证据 | 必须列入缺口 |

### 6. 证据强度与结论匹配

```
5 级 独立审计 / 实验 / 计量模型
4 级 第三方调研（方法可追溯）
3 级 第三方平台数据
2 级 企业系统后台导出
1 级 内部 PPT / 口头结论
```

若核心结论是"营销导致增长"，只靠 1–2 级证据不够，必须降到"贡献/相关"表述。

### 7. 输出

```
证据审计结论

登记：24 条证据 / 18 条主张
可提交状态：14 VERIFIED / 5 PARTIALLY / 3 USER_ASSERTED / 1 CONTRADICTED / 1 MISSING

阻断问题（P0×2）
  - E-09 引用文件不存在（quarterly_report.pdf）→ 虚构来源风险
  - E-12 与 E-18 数值冲突（51% vs 41%）→ 必须确定唯一口径

需降级表述（P1×3）
  - C-04 "营销带来 37% 增长"：仅 2 级证据 + 无对照 → 改为"同期增长 37%"

建议补证（按优先级）
  1. 品类基准（第三方）→ 支撑份额主张
  2. 618 大促拆分 → 支撑归因
  3. 曝光去重数据（媒介代理）→ 修正触达表述

保密处理
  - E-01（含具体销售额）用于创意视频前须改为指数表达
```

## 高频缺陷清单（主动扫）

| 缺陷 | 典型表现 |
|---|---|
| 虚构来源 | "据 XX 研究"查无此研究 |
| 页码虚构 | 引用 P12 但内容在 P30 |
| 张冠李戴 | 真文件支持的是另一件事 |
| 数值不一致 | 正文与附件不同 |
| 周期不一致 | 主张活动期，数据含活动前 |
| 一证多源 | 同一数据写成三源印证 |
| 口径漂移 | 分子分母不同人群 |
| 平台指标冒充生意 | 曝光当销售 |
| 机密外泄 | 真实金额进了公开视频 |

## 红线

- ❌ 不得把"文件哈希一致"说成"数据真实"
- ❌ 不得把企业自报数据说成"经审计"
- ❌ 不得在存在 CONTRADICTED 时声称已验证
- ✅ 发现缺陷必须如实报告，包括对自己不利的
