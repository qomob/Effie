# 工作流：商业实效审计（attribution-audit）

**对应模块**：M05 + M07　**触发**："这些数据能不能证明营销有效"

## 先问三个问题

1. 这个数字是**生意结果**还是**传播指标**？
2. 有没有**对照**（品类/历史/对照组）？
3. 除了营销，还有什么能解释它？

三个都答不好，就不构成"实效"。

## 步骤

### 1. 指标清点与分层

把所有数字按四层分类：

```
生意层：销售额、销量、份额、毛利、新客、复购、渗透率
消费者层：认知、偏好、意向、考量
传播层：曝光、触达、互动、完播、声量
效率层：ROI、ROAS、CAC、LTV
```

**规则**：目标在哪层，成果必须在哪层。用曝光回答生意目标 = 成果薄弱（官方明示）。

### 2. 口径审计

```bash
python3 scripts/validate_metrics.py --file metrics.json
```

会检出：ROI/ROAS 混用、百分比 vs 百分点、低基数、周期缺失、无基准、
虚假精度、分母缺失、层级错配、目标无对应成果。

### 3. 归因审查

```bash
python3 scripts/audit_attribution.py --file attribution.json
```

核心判定：

| 你有 | 最高只能说到 |
|---|---|
| 只有前后对比 | C 级（相关性） |
| 同比 + 品类基准 | B 级（有一定证据的贡献） |
| 对照/实验/增量/MMM（且前提成立） | A 级（有充分证据的因果贡献） |
| 数据不足 | D 级（无法确定） |
| 有反证 | E 级（存在相反证据） |

**越级 = P0 缺陷**，必须改口。

### 4. 14 类替代因素逐项排查

| 因素 | 排查问题 | 若未排查 |
|---|---|---|
| 季节性 | 去年同期是否本来就有峰值 | 至少说明"已用同比控制" |
| 行业整体增长 | 品类同期涨幅多少 | 必须拿到品类数据 |
| 产品升级 | 同期是否换配方/包装 | 说明无变化 |
| 降价促销 | 是否有折扣活动 | 拆分价格效应 |
| 渠道扩张 | 是否新增门店/平台 | 按新增覆盖折算 |
| 铺货率 | 上架率是否提升 | 给铺货数据 |
| 竞品退出 | 竞品是否涨价/断货 | 说明竞品动态 |
| 价格变化 | 单价变动贡献多少 | 拆价量 |
| 宏观环境 | 政策/经济/气候 | 引外部数据 |
| 品牌历史趋势 | 活动前 12 个月斜率 | 给趋势图 |
| 自然增长 | 无营销时的常态增速 | 趋势外推扣除 |
| 同期其他活动 | 是否并行大促/代言事件 | **必须拆分** |
| 统计口径变更 | 归因窗口/去重规则变了？ | 说明口径一致性 |
| 数据质量 | 重复计数/机器人/退货 | 说明清洗规则 |

### 5. 增量拆解（如数据允许）

```
总变化
 − 自然增长（趋势外推）
 − 季节性（去年同期修正）
 − 价格/促销效应
 − 铺货/渠道可得性
 − 竞品让出份额
 = 营销传播可解释余量（给区间，不给点值）
```

完成不了就明说"未能排除以下因素"，结论降到 C 级。

### 6. 输出

```
实效审计结论

指标分层：
  生意层：份额 +2.1pt（有品类对照 ✓）
  传播层：曝光 11.3 亿（无去重说明 ✗）
  效率层：ROAS 8.5（被误标为 ROI ✗，须改称）

口径问题（P1×3）：
  - M2 曝光被称为"触达"，未去重
  - M5 增长率无基线，疑低基数
  - M7 精度到小数点后 4 位

归因结论：B 级（有一定证据的营销贡献）
  依据：有品类对照 + 同比，但缺对照组
  不可说："营销带来 xx 增长"（因果关系未建立）
  可以说："活动期份额提升 2.1pt，同期品类增长 12%，品牌增速为品类 1.75 倍"

必须补：
  1. 618 大促贡献拆分（数据团队）
  2. 曝光去重触达口径（媒介代理）
  3. 2019–2024 基线趋势（客户市场部）

若无法补：第四部分建议改为"贡献"表述，不写"导致"
```

## 红线

- ❌ 相关性写因果
- ❌ 自然增长归功营销
- ❌ 用"赋能/引爆/带动"隐式跨越因果
- ❌ 编造实验或归因模型
- ✅ 主动披露不利因素反而加分（4.2 官方要求）
