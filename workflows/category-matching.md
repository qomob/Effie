# 工作流：全量类别匹配与投报策略（category-matching）

**对应模块**：M04　**触发**："适合投哪些类别"

## 铁律

**类别匹配 ≠ 关键词相似度。** 必须综合 7 个维度判断；关键词只用于召回候选。

## 步骤

### 1. 召回候选（不做结论）

```bash
python3 scripts/category_query.py --award EFFIE_GC_MAIN --candidates case.json --top 15
python3 scripts/category_query.py --award EFFIE_GC_MAIN --search 私域
python3 scripts/category_query.py --award EFFIE_GC_MAIN --track 生意增长赛道
```

脚本输出明确标注"这是召回，不是匹配结论"。

### 2. 七维核验（逐个候选）

| 维度 | 检查问题 |
|---|---|
| ① 类别资格 | `special_rules` 是否全部满足？（小预算/份额/年限） |
| ② 核心商业问题 | 案例解决的是不是这个类别定义指向的问题？ |
| ③ 策略与执行机制 | 类别要求的机制（如"电竞元素""私域运营""跨界合作"）是否真是案例的机制？ |
| ④ 主要成果类型 | 类别看重的成果（如"转化""声誉""设计商业价值"）是否是案例的主成果？ |
| ⑤ 关键证据 | 该类别定义要求呈现的证据是否齐备？ |
| ⑥ 类别竞争力 | 有无真实、可比的获奖案例或其他证据支持相对竞争力？未知就标未知 |
| ⑦ 组合合规 | 总数 ≤4，行业类 ≤1 |

### 3. 查类别定义原文

```bash
python3 scripts/category_query.py --number 55
```

输出含：官方定义、特殊资格、判断维度、定义是否与兄弟类别共用。

> 类别定义中共用定义的情况（如 31/32 共用、36–40 共用），说明这些是"按适用对象/载体再分"，
> 选择时看具体适用对象，不看定义差异。

### 4. 输出三件事

**A. 推荐组合（含优先级）**

```
主推：55 持续成功
  理由：案例已有 3 年连续数据，核心元素（主题/代言人）延续
  证据：2023/2024/2025 三年 campaign 物料与数据（E-11, E-12, E-13）
  风险：需用专用参赛表，视频可至 4 分钟（制作成本上升）

次推：46 场景营销
  理由：核心机制是"场景绑定"，与类别定义高度一致
  证据：场景投放数据与到店转化（E-21）
  风险：需强化"场景如何被精准满足"的阐述

备选：120 生意增长-生活方式-产品
  理由：成果为生活方式认同提升 + 销售增长
  风险：与 46 叙事重叠，应核对差异化叙事是否足够，不臆测评委
```

**B. 明确不推荐 + 原因**

```
不投 53 小预算：媒体支出 1200 万，超全国 500 万上限（BLOCKED）
不投 62 挑战者：品牌份额 22%，不符合 <15% 定义
不投 107 私域-导购赋能：案例无导购/1v1 环节
```

**C. 多类别差异化叙事**

同一案例投多个类别时：
- **共享**：全部事实、数据、证据（`check_consistency.py` 会校验）
- **差异化**：阐述重心、执行摘要的 200 字"为何该类别"回答、成果的呈现顺序

| 类别 | 叙事重心 |
|---|---|
| 55 持续成功 | 三年机制延续与逐年进化 |
| 46 场景营销 | 场景如何精准满足需求 |
| 120 生活方式 | 品牌如何成为生活方式的载体 |

## 3. 类别组合的三种合法形态

| 形态 | 说明 | 适用 |
|---|---|---|
| 1 行业类 + 3 专项类 | 最常见 | 行业属性强且专项机制明确 |
| 4 专项类 | 不投行业类 | 跨行业或机制导向 |
| 1 行业类 + 1–2 专项类 | 保守 | 预算有限或只押最强 |

**行业类最多 1 个**（所有奖项一致，汽车奖称"产品与服务类"）。

## 4. 常见误投（必须主动提醒）

| 误投 | 为什么错 | 正确做法 |
|---|---|---|
| 把"情感营销"的案例投"公益影响" | 无社会议题实质 | 投 42 情感营销 |
| 把品牌内容案例投"媒体创意" | 创意非媒体主导 | 投 34/35 品牌内容 |
| 把一次 campaign 投"持续成功" | 不足 3 年 | 投对应单年类别 |
| 把 DTC 品牌案例投"零售"行业类 | 行业类别错位 | 投 76 DTC 专项 |
| 把台湾案例报"全球化奖" | 地域口径错误 | 报主奖项 |

## 5. 输出附官方依据

每个推荐/不推荐都要给出：

```
类别 55 定义：（来源：2026_大中华区艾菲奖_类别定义.pdf 类别55）
类别数量限制：同一营销活动至多4个类别，行业类最多1个
  （来源：2026_大中华区艾菲奖_类别定义.pdf P1）
```
