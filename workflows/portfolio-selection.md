# 年度案例海选与组合决策（按需）
共用 `value-discovery.md` 与 `category-matching.md`；只在用户存在多个项目或类别、预算约束时调用。
1. 每案记录项目、品牌、期间、投入、原目标、机制、主要结果、证据、资格状态。
2. 先隔离硬资格不符、核心事实矛盾及未证主张；区分可补证与不可补救。不以短期销售或项目规模作为统一标准。
3. 对合格候选比较目标难度、相对基准、效果可信度、差异化机制、类别契合及材料复用成本。未实现的硬规则必须保留未知。无可比案例库时不假装知道类别竞争密度。
4. 年度、奖项、轮次、价格查规则并核对官方；制作和人力以真实报价、可用工时、预算为准，未知留空。按约束比较增报一个类别或补证一个项目的实际边际成本与收益，不因固定分数分配类别数量。
5. 输出推荐、条件推荐、不建议及待决四组；逐案说明依据、反证、成本、下一步及可撤回条件。禁止保证获奖或估算无依据奖级概率。
