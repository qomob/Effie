# 工作流：参赛资格与规则判断（eligibility）

**对应模块**：M02　**触发**："能不能报""会不会被取消资格"

## 铁律

**资格校验优先于一切。** 资格 BLOCKED 时，停止评分、停止美化、停止类别优化。

## 步骤

### 1. 锁定三参数

```
award_id   → 13 个奖项之一（规则不同！）
year       → 知识库仅 2026
category   → 未定类别则无法判资格（类别定义本身是资格条件）
```

### 2. 跑脚本

```bash
python3 scripts/validate_eligibility.py --case case.json --award EFFIE_GC_MAIN
```

退出码：`0` PASS / `1` CONDITIONAL 或 BLOCKED / `3` UNKNOWN

### 3. 八项检查含义

| 检查 | 内容 | BLOCKED 条件 |
|---|---|---|
| C00 年度 | 知识库是否覆盖该年 | 非 2026 → UNKNOWN |
| C01 时间窗口 | 2025-01-01 ~ 2026-06-30 | 2026-06-30 后才开始实施；或结束早于窗口起点 |
| C02 地域 | 见下 | 地域与奖项要求不符 |
| C03 类别数量 | ≤4，行业类 ≤1 | 超过上限 |
| C04 实测性质 | 须真实投放 | 试点/测试项目 |
| C05 类别特殊资格 | 见类别 `special_rules` | 小预算超限、份额≥15%、不足3年、新品超3月等 |
| C06 盲评匿名 | 无代理公司标识 | 材料出现代理公司名称/LOGO |
| C07 数据来源 | 主张有证据 | 事实类主张无证据 |

### 4. 地域口径（最易错）

| 奖项 | 要求 |
|---|---|
| `EFFIE_GLOBAL` | **海外地区**投放 |
| 其余 12 个 | 大中华区（中国大陆及港澳台） |

拿大中华区案例报全球化奖 = BLOCKED。反向亦然。

### 5. 类别特殊资格速查

| 类别 | 约束 |
|---|---|
| 53/54 小预算 | 城市 ≤100万 / 省级 ≤200万 / 全国 ≤500万；须为该投放期唯一活动；排除产品线扩展 |
| 99 电竞-小预算 | 同上预算门槛 |
| 62 挑战者品牌 | 市场份额 **<15%** |
| 50 以弱胜强-传统 | 成立 **≤5 年**，须证明初始弱势 |
| 51 以弱胜强-形势 | 须证明处于危机/结构性困境 |
| 52 品牌活化 | 低迷期数年 + 至少 6 个月销售回升 |
| 55/100 持续成功 | 连续 **≥3 年**，用专用参赛表，视频 ≤4 分钟 |
| 115 生意增长-新品 | 上市 **≤3 个月** |
| 93 环境公益 | 主要战略目标须为改变受众环保行为 |
| 127 产品与包装 | 须为带条形码/销售标识符的商业销售品 |

### 6. 四种结论怎么用

| 结论 | 含义 | 下一步 |
|---|---|---|
| `PASS` | 条件已核验通过 | 可进入诊断/匹配 |
| `CONDITIONAL` | 有事实待补 | 给补充清单，**不得**说"可以报" |
| `BLOCKED` | 明确不合规 | 说明原因 + 有无补救路径（多数不可补救） |
| `UNKNOWN` | 缺规则或关键事实 | 说明缺什么，不得猜测 |

### 7. 禁止

- ❌ 因案例质量高而忽略资格问题
- ❌ 把用户"我们想报"当作资格满足
- ❌ 用评分抵消不合规
- ❌ 在 UNKNOWN 状态下输出"应该可以"
