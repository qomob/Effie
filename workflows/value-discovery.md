# 案例价值发现与投报决策 V1.1.1

此工作流是专业判断协议，不是已经盲测的自动专家引擎。先诊断后撰写；先证据后故事。不要根据用户期待的奖级倒推价值。

## 1. 事实冻结与目标适配
识别客户、品牌、活动期间、范围、商业模式、利益相关者、预算、目标、基线、成果、已有材料。明确哪些是已核事实、待核声明、计算和推断。目标必须来自立项或同期记录，不能事后发明。保留未达目标。

| 类型 | 价值假设与优先指标 | 反方挑战 |
|---|---|---|
| 商业增长 | 净收入、贡献利润、增量份额 | 大促、铺货、自然增长 |
| 品牌建设 | 可验证的心智、购买意向、品牌资产变化 | 样本漂移、短期曝光 |
| B2B | 合格商机、成交率、销售周期 | 销售团队变动、渠道归因 |
| 社会公益 | 目标行为变化、社会效益 | 只有触达/自报、外部政策 |
| 用户运营 | 留存、复购、LTV、边际成本 | 补贴依赖、选择偏差 |
| 营销效率 | CAC、增量利润、边际效率 | 成本口径不全、透支未来 |

## 2. 竞争性价值假设
至少提出两个互相竞争的解释，包括一个无营销贡献的解释。每个写清商业挑战、受众障碍、洞察证据、策略机制、创意触点、行为改变、目标结果、证据与可能证伪条件。没有证据只列为假设，不进正式叙事。关注结果的量级、难度、可持续性及相对基准，而非创意形容词。

## 3. 类别决策
用官方快照召回候选类别，逐一列定义、硬约束、未实现检查、主张-证据匹配、竞争性叙事、补证成本。未知硬条件不得视为合格。每个类别保留独立表单和相同事实底座。缺真实可比获奖案例时只能说竞争基准未知，不预测奖级或概率。

## 4. 反方评审
先独立写出拒绝理由与可证伪点，再形成正方与最终裁决。必须检查替代解释、误用因果、数据选择性披露、创意与策略断裂、证据不足、类别错配。按「建议投报 / 补证后再判 / 不建议 / 无法判断」输出；事实、规则和证据缺口优先于分数。公益及品牌项目不得仅因无短期销售而淘汰；仅曝光而无与目标匹配的可测量结果仍是风险。

## 5. 决策输出模板
核心价值假设 | 证据ID/缺失 | 反证 | 可证伪测试 | 结论强度 | 最适类别/未知条件 | 预计人工工时及待核报名费 | 投报裁决。与用户确认优先补证和截止时间。未授权不得对外发送或发布案例。

## 6. 决策顺序（唯一执行协议）
资格硬约束 → 目标与原始证据 → 实效/归因结论强度 → 类别契合与竞争价值 → 实际成本及补证机会。硬伤不可被任何内部评分抵消。12项诊断仅可作为缺口提示，不产生总分阈值决策。类别竞争力、人工工时及费用未知就留空，不虚构报价或奖级。材料不齐时可做草稿与补证计划，推断只进入 `draft_hypotheses`，不得进入正式 `claims`/`answers`。
