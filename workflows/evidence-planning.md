# 工作流：实效证据预埋（evidence-planning）

**对应模块**：M12　**触发**："项目还没开始，怎么为明年报奖做准备"

## 核心洞察

**报奖不是结案后补材料，而是立项时就开始建证据链。**
等到结案再想"能不能证明有效"，往往已经来不及做对照、没留基线。

## 关键动作：在项目开始前做这 8 件事

### 1. 明确商业挑战与可失败的假设

```
我们相信：〔目标受众〕在〔场景〕下，因为〔机制〕，
         会〔行为改变〕，从而带来〔商业结果〕。
若〔反向信号〕出现，则假设不成立。
```

写成可证伪的形式。没有反证条件的假设无法验证。

### 2. 目标设定留痕（最重要）

| 动作 | 产出 | 为什么 |
|---|---|---|
| 立项会定目标 | 会议纪要 + 日期 | 证明目标不是事后倒推 |
| 目标写入 brief | 带版本的 brief 文件 | 可追溯 |
| 目标邮件确认 | 客户回复邮件 | 双方确认 |

**评委最常质疑的就是"目标是不是做完了才写的"。** 有时间戳就赢一半。

### 3. 登记基线数据（项目启动前）

必须在上线**前**采集：

```
品类规模与增速 | 品牌份额 | 品牌认知/偏好 | 新客占比
复购率 | 客单价 | 搜索指数 | 社媒声量
```

要求：至少 12 个月历史（做趋势外推），最好 24 个月。

### 4. 设计对照（决定归因等级）

| 方案 | 成本 | 归因等级 |
|---|---|---|
| 地域对照（选 2–3 个可比城市不投放） | 中 | A 级潜力 |
| Holdout 人群（保留 5–10% 不触达） | 低-中 | A 级潜力 |
| 分阶段投放（先 A 区后 B 区） | 低 | B-A 级 |
| 仅前后对比 | 零 | C 级上限 |

**强烈建议至少做一个 holdout 或地域对照。** 这是把结论从"相关"提升到"因果"的唯一廉价方法。

### 5. 指标体系设计（分层）

```
商业层（1 个）：份额 or 销售额 or 毛利
营销层（1–3 个）：新客率 / 复购频次 / 渗透率
战役层（1–3 个）：认知 / 联想 / 声量
```

每层给：指标名 + 口径定义 + 采集频率 + 负责人 + 数据源系统

### 6. 素材留存计划

| 素材 | 留存要求 |
|---|---|
| 出街物料 | 原始文件 + 投放实拍/截图（带媒介环境） |
| 投放数据 | 平台后台导出（含日期范围） |
| 创意过程 | 提案稿、迭代记录（证明策略推导） |
| 授权文件 | 肖像/音乐/IP 授权书（提前签） |

**提前解决授权**：代言人、音乐、IP 的授权范围要覆盖"用于奖项申报与公开传播"，否则入围后无法公开。

### 7. 中期检查点

项目中期（如上线 4 周）做一次：

- 各层指标 vs 基线
- 是否需要调整策略（并留记录，这正是第三部分"优化动作"的素材）
- 数据采集是否有断点

### 8. 结案归档

按证据登记簿格式归档，字段见 `templates/evidence-register.csv`。

## 输出：证据预埋方案

```
项目：〔名称〕 预计上线：2026-03

一、可证伪假设
  ...

二、目标留痕计划
  □ 立项会 2026-01-15（纪要存档）
  □ Brief v1 含目标（2026-01-20）
  □ 客户邮件确认（2026-01-22）

三、基线采集清单（上线前必须完成）
  | 指标 | 口径 | 数据源 | 负责人 | 截止 |
  | 品类增速 | 尼尔森月度 | 客户市场部 | 张三 | 2026-02-28 |
  ...

四、对照设计
  方案：地域对照，选杭州/成都/西安为对照城市（不投放）
  周期：与投放期一致
  预期归因等级：A 级

五、指标体系
  商业层：份额（月度）
  营销层：新客占比（周度）、复购频次（月度）
  战役层：品牌联想度（前后测）

六、素材与授权
  □ 代言人授权含"奖项申报"条款
  □ BGM 商用授权
  □ 出街实拍留存计划

七、中期检查点
  2026-04-15（上线 4 周）

八、归档要求
  按 evidence-register.csv 格式，结案后 2 周内完成
```

## 重要限制

**未实施的项目不具备参赛资格。** 官方明确："未经投放或实施的参赛案例不具备参与角逐的资格。"

所以：
- 本工作流产出的是**未来证据链**，不是参赛材料
- 不得把计划描述为已执行
- 不得用于当前年度提交

## 红线

- ❌ 不得为未实施项目编写"已执行"叙述
- ❌ 不得事后补造基线数据
- ❌ 不得虚构对照实验结果
- ✅ 明确告知用户：现在做规划，最快也要下一个竞赛年度才能用
